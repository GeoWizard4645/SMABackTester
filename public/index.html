Run it on your own computer

Everything on this site is open source. Running it locally is faster (the moving-average test takes a second or two instead of about 30, and there is no 30 MB download), and it lets you change the code, the settings or the data.

View the code on GitHub Download as a ZIP

1. What you need

  • Python 3.10 or newer (check with python3 --version).
  • Git, or just use the ZIP button above and unzip it.
  • An internet connection, because prices come from Yahoo Finance, Kalshi and Coinbase. Node.js is only needed if you want to rebuild the website file.

2. Get the code

git clone https://github.com/geowizard4645/SMABackTester.git
cd SMABackTester

3. Set up Python (once)

This makes a private folder for the libraries, so nothing else on your computer is touched.

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

On Windows use py -m venv .venv and .venv\Scripts\activate instead of the first two lines. Next time you only need the activate line.

4. Start the website

python app.py

Open http://127.0.0.1:5050. It is this same page, but the moving-average test now runs in native Python on your machine. Press Ctrl+C in the terminal to stop it.

5. Or skip the website and use the command line

Each test also works as a plain script that prints tables and saves PNG charts.

# moving-average test: S&P 500, 200-day vs 174-day
python main.py
python main.py --ticker BTC-USD ETH-USD AAPL        # several assets
python main.py --target 50 --control 40             # test a different line
python main.py --era-years 1970 1990 2010           # your own time periods

# Kalshi 15-minute test
python kalshi_lab/main.py --entry-checkpoint 5m --min-price 20 --max-price 50
python kalshi_lab/main.py --source synthetic --bias 0   # a fair simulated market
python kalshi_lab/main.py --series KXETH15M --days 14

# run the tests
pytest -q tests

Add --help to any command to see every option.

7. Publish your own copy

The live site is one file, public/index.html, plus a small Cloudflare Worker that fetches prices. To rebuild and publish it:

python build_static.py          # rebuilds public/index.html (needs Node.js)
git add -A && git commit -m "Update site" && git push
npx wrangler deploy             # or connect the GitHub repo in Cloudflare

The README on GitHub has the full deployment notes.

If something goes wrong

  • "Address already in use": another program has port 5050. Run python app.py --port 8000 and open that port instead.
  • No data for a symbol: Yahoo sometimes rate-limits. Wait a minute and retry, check the symbol, or upload your own CSV on the Moving average page.
  • Kalshi data will not load: Kalshi limits how fast it answers, so large pulls take a minute. Choose "Simulated data" to try the tool with no network.
  • pip or python3 not found: try python -m pip install -r requirements.txt, or py on Windows.
